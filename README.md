# repl
Read-Eval-Print-Loop のテンプレート

## はじめに

このプロジェクトは、プログラミング言語解釈系のREPL部分の雛形を提供するライブラリ（になる予定）です。

## 構成の概要

```
I/O --> 文字列 --> [文字列] --> [入力] --> REPL --> [出力] --> [文字列] --> 文字列 --> I/O
          |           |            |                  |            |           | 
          +---------->+----------->|----------------->|----------->|---------->|
             split       decoder           repl          encoder      unsplit
```
